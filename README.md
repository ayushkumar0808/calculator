# 🧮 Calculator

A simple and beginner-friendly **Calculator Mini Project** built using **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript **functions, DOM manipulation, and event handling**.

## 🚀 Live Demo

👉 **[View Live Calculator](https://ayushkumar0808.github.io/calculator/)**

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Number input
- 🔹 Decimal numbers
- 🧹 Clear (`C`) button
- 🟰 Calculate result using (`=`)
- 📱 Simple and responsive UI

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality and DOM manipulation

## 🧠 JavaScript Concepts Practiced

- Variables

The main purpose of this project is to strengthen my understanding of **JavaScript functions, DOM manipulation, and event handling** by building a practical mini project.
